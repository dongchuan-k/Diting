# 谛听（DiTing）

> **⚠️ 仅支持 macOS（Apple Silicon M系列芯片），Windows 不支持。**

> 谛听 — 微信聊天 AI 总结助手。
>
> 自动提取微信聊天记录，用 AI 帮你总结群聊和私聊内容。
>
> 适用于：每天想快速了解微信里发生了什么的人——无论是群聊还是私聊。

---

## 这是什么？有什么用？

简单说：**谛听会自己进微信里提取聊天记录，整理成总结报告给你。**

可以用在：
- 早上看一眼群里昨晚聊了什么
- 跟某人的私聊内容太多，让 AI 帮你提炼重点
- 每天自动生成群聊日报，不用自己一条条翻

## 工作原理

```
微信 Mac 版本地数据库
    ↓ 内存扫描获取加密密钥
解密后的 SQLite 数据库
    ↓ 导出指定群聊/联系人消息
纯文本聊天记录
    ↓ AI 总结分析 (DeepSeek / ChatGPT / 你喜欢的工具)
结构化总结报告
```

本项目是一个**一键安装包**，替你搞定解密工具链的安装配置。你只需要完成下方的前置条件即可。

## 你需要准备什么？

你的 Mac 只需要：
- **macOS（Apple Silicon 芯片）**就是 M 开头的芯片，M1、M2、M3、M4、M5 都可以

> ```

## 前置条件（请先完成！）

### 1. macOS Apple Silicon 电脑
本工具支持所有 Apple Silicon（M 系列芯片）的 Mac。Intel Mac 暂不支持。

### 2. 安装微信 4.x 版本
微信 Mac 版必须为 **4.x 版本**（如 4.0.0 或更高）。可在微信官网下载：https://mac.weixin.qq.com/

打开微信 → 菜单栏「微信」→「关于微信」可查看版本号。

### 3. 关闭 SIP（系统完整性保护）⚠️ 关键步骤

SIP 是 macOS 的一道安全锁。微信把聊天记录加密存在电脑里，我们的工具需要读取它，所以得先暂时解开这把锁。**密钥未变化时通常不影响；微信升级、重新登录或密钥变化时需要重新提取。**

> 🎥 **如果你觉得看文字麻烦，可以在抖音/B站搜索「Mac 关闭 SIP 教程」，有很多视频演示。**

---

#### 第一步：关机（不是重启）

点击屏幕左上角苹果图标 🍎 → **「关机」**。

等待电脑完全黑屏、风扇停止、键盘灯熄灭。

> ⚠️ 不要选「重新启动」，要选「关机」。

- **iMac 一体机**：背后左下角的电源键

**操作：**

1. **按住电源键不要松手**
2. 大约 5~10 秒后，屏幕会亮起，显示 **"Loading startup options…"**（正在载入启动选项）
3. **继续按住，直到看到这个画面为止**（不要一看到苹果logo就松手）
4. 等出现下面的画面后，松开电源键

> ❗ 如果你看到的是输入密码的登录界面，说明没按够久或没关机彻底。关机重试。

正常会看到这样一个界面：
- 左侧有一个「选项」（Options）⚙️ 图标
- 下面写着「适用于…的其他项目」
- 右侧显示你的硬盘图标

#### 第三步：进入终端

1. 点击 **「选项」** ⚙️ → 点击 **「继续」**
2. 选择你的用户账户 → 输入电脑的开机密码 → 点击 **「下一步」**
3. 稍等一会儿，会进入一个看起来像恢复模式的界面
4. 看屏幕**最顶上的菜单栏**（不是窗口里面，是整个屏幕最上面那条）：
   - 点击 **「实用工具」**（Utilities）
   - 在下拉菜单里选择 **「终端」**（Terminal）
5. 屏幕上会弹出一个黑白窗口，里面有一个光标在闪烁 👈 这就是终端

在终端窗口里，**一字不差**地输入以下命令（可以直接复制下面这行，然后在终端里按 `Command+V` 粘贴）：


如果看到提示 **`Successfully disabled System Integrity Protection`**（成功禁用系统完整性保护），说明**关闭成功了** ✅

> 如果需要输入密码，终端会提示 **"Password:"**，输入你的开机密码然后回车（打字时屏幕上看不到字符是正常的）。

---

#### 第五步：重启电脑

1. 点击左上角苹果图标 🍎
2. 选择 **「重新启动」**
3. 电脑会正常重启，进入正常的 macOS 桌面

---

#### 第六步：验证是否关闭成功

电脑重启进入桌面后：

1. 打开 **「终端」**（在「启动台」→「其他」文件夹里，或者按 `Command+空格` 搜索「终端」）
2. 输入以下命令后回车：
   ```bash
   csrutil status
   ```
3. 看屏幕上输出的结果：

| 显示内容 | 什么意思 |
|---------|---------|
| `System Integrity Protection status: disabled` | ✅ **关闭成功**，可以继续下一步安装 |
| `System Integrity Protection status: enabled` | ❌ **没关成功**，请从头再来一遍 |

> 💡 **记住**：关闭 SIP 只是临时操作。等安装完成、密钥提取成功后，我们会教你重新打开它。

### 4. 确保微信已登录
运行工具前，微信必须处于**已登录状态**（在 Mac 上打开微信，扫二维码登录）。
> ⚠️ 注意只开**1 个微信**，不要同时开 WeChat 和 WeChat2。

## 安装后：恢复 SIP（强烈推荐）

密钥已经提取成功，现在可以重新锁上 SIP 了。

> ⚠️ **重要说明**
> - 关闭 SIP 会降低系统安全性，完成安装后应尽快恢复
> - 恢复 SIP 后，如果微信退出重新登录、升级版本或数据库密钥变化，需要重新提取密钥
> - 恢复 SIP 不影响已有密钥的使用，只要密钥文件存在就可以继续解密
> - 如果后续运行提示密钥失效，按以下步骤处理：
>   1. 再次关闭 SIP（参考前面的教程）
>   2. 重新运行安装脚本提取密钥
>   3. 提取成功后再次恢复 SIP

### 第一步：重新关机进恢复模式

操作和关闭时完全一样：
1. 🍎 → **「关机」**，等电脑完全熄灭
2. **按住电源键不放**，直到出现 **"Loading startup options…"**
3. 点击 **「Options」⚙️** → 输入密码
4. 看顶部菜单栏 → **「Utilities」** → **「Terminal」**

### 第二步：执行打开命令

在终端里输入（可以复制粘贴）：

```bash
csrutil enable
```

按回车。看到 **`Successfully enabled System Integrity Protection`** ✅ 说明打开成功。

### 第三步：重启

🍎 → **「重新启动」**

### 第四步：验证是否成功

桌面打开终端，输入：

```bash
csrutil status
```

| 终端显示 | 什么意思 |
|---------|---------|
| `System Integrity Protection status: enabled` | ✅ **恢复成功** |
| `System Integrity Protection status: disabled` | ❌ 没成功，再试一次 |

恢复后工具继续使用现有密钥文件解密。密钥文件存储在 `~/.diting/wechat-db-decrypt-macos/wechat_keys.json`。
如果将来密钥失效（例如微信重新登录），需要再次关闭 SIP → 提取密钥 → 恢复 SIP。

## 使用方法

> 💡 **每次跑总结时，谛听会自动重新解密数据库**，所以你任何时候运行拿到的都是最新的聊天记录。

安装完成后，在终端里直接使用 `diting` 命令：

### 系统自检（装好后先跑一次）

```bash
diting doctor
```

检查环境是否就绪，自动检测 Python、依赖、微信路径、密钥等。

### 刷新密钥

微信重新登录后密钥会失效，运行：

```bash
diting keys refresh
```

会自动删除旧密钥并重新提取（需要微信处于登录状态，SIP 临时关闭）。

### 列出会话

```bash
diting list                # 列出所有会话（群聊+联系人）
diting list --groups       # 只列群聊
diting list --contacts     # 只列联系人
```

### 导出消息

```bash
# 导出某群聊最近 100 条消息
diting export -c "项目对接群" -n 100

# 导出到文件
diting export -c "项目对接群" -n 200 --out ~/Desktop/chat.md

# 导出今天的消息
diting export -c "项目对接群" --today

# 导出昨天的
diting export -c "项目对接群" --yesterday
```

### AI 总结（推荐）

先设置环境变量（或在 config.yaml 中配置）：
```bash
export DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

```bash
# 总结指定群今天的内容
diting summarize -c "项目对接群" --today

# 总结指定私聊
diting summarize -c "张三" --today

# 一键总结所有配置的会话
diting summarize --all --today

# 总结昨天的
diting summarize --all --yesterday
```

> ⚠️ **日期筛选说明**：`--today` / `--yesterday` 目前是先拉取最近的消息再按日期过滤，超活跃群可能因消息过多而遗漏部分内容。后续版本会优化为数据库级别筛选。

### 搜索消息

```bash
diting search "预算"
diting search "报价"
```

> 💡 会话名填的是**微信会话列表里的名字**，不管是群名还是联系人名字都可以。

## 配置说明

编辑 `~/.diting/config.yaml`，完整结构如下（也可以用 `diting init` 自动生成）：

```yaml
# ── 微信相关 ──
wechat:
  account_dir: auto
  temp_dir: ~/.diting/tmp
  output_dir: ~/.diting/outputs

# ── 总结设置 ──
summary:
  message_limit: 200
  language: zh-CN
  output_format: markdown

# ── 要监控的会话 ──
sessions:
  groups:
    - name: 项目对接群
      enabled: true
    - name: 部门群
      enabled: true

  contacts:
    - name: 张三
      enabled: true

# ── AI 总结（可选） ──
ai:
  enabled: false
  provider: deepseek
  model: deepseek-chat
  base_url: https://api.deepseek.com
  temperature: 0.3
  api_key_env: DEEPSEEK_API_KEY

# ── 隐私脱敏 ──
privacy:
  redact_before_ai: true    # 建议 AI 模式默认开启
  redact_phone: true
  redact_email: true
```

> 💡 API Key 建议通过环境变量 DEEPSEEK_API_KEY 设置，不要写在配置文件里。

## 🛡️ 隐私与安全（必读）

本工具涉及微信聊天记录，请务必理解以下事项：

### 数据去哪了？

- **不解密不处理**：聊天记录只在你自己的 Mac 上处理
- **导出模式**（默认）：聊天记录保存在本地，不发给任何第三方
- **AI 总结模式**（需手动启用）：聊天内容会发送给 DeepSeek / OpenAI 的 API 服务
  - 你可以在 `config.yaml` 中关闭 `ai.enabled` 来禁用此功能
  - 启用前建议开启脱敏：`privacy.redact_before_ai: true`

### 使用建议

1. **不要处理你不该看的数据** — 注意群聊和私聊涉及他人隐私
2. **不要上传到公共平台** — 导出文件包含聊天内容，注意保存位置
3. **遵守公司信息安全规定** — 不要用此工具处理涉密或合规受限的信息
4. **及时恢复 SIP** — 密钥提取后建议立即恢复 SIP，保障系统安全
5. **密钥也是敏感文件** — `wechat_keys.json` 不要分享或提交到 git
6. **API Key 也是敏感信息** — 建议通过环境变量设置，不要写入配置文件

### 本工具不会做的事

- ❌ 不会上传你的聊天记录到第三方服务器（除非你启用了 AI 总结）
- ❌ 不会修改微信的原始数据库
- ❌ 不会在日志里打印数据库密钥或 API Key
- ❌ 不会自动分享你的任何数据

## ⚠️ 已知问题：微信弹出"数据库损坏"提示

**现象：** 运行完谛听后，下次打开微信 Mac 版时弹出一个提示框，说"数据库损坏"。

**原因：** `decrypt_db.py` 解密微信加密数据库时，使用的是 Read-Write 模式，SQLCipher 会在原数据库目录下生成 `-wal` 和 `-shm` 临时文件。微信下次打开时发现了这些异常文件，就误报为"损坏"。

**这不是真正的数据损坏**，微信会自动修复，不会丢失任何聊天记录。

**解决方案（已实现）：** 最新版 `summarize.py` 的 `refresh_data()` 函数会自动：
1. **复制** 微信的数据库目录到 `~/.diting/tmp/`
2. 在**副本**上执行解密
3. 解密完成后**自动清理**临时脚本，临时数据目录默认保留（防止重复复制），可在 `config.yaml` 中配置 `wechat.temp_dir` 路径

微信的原始数据库全程不被触碰，所以不会再弹出任何提示。

## 常见问题

### Q: 密钥提取失败 / keys not found
**原因：** 微信版本不对、SIP 未关闭、或者有多个微信进程。

**解决：**
1. 确认微信是 4.x 版本
2. 确认 SIP 已关闭：`csrutil status` → `disabled`
3. 关闭所有微信进程，重新打开，再试一次

### Q: 解密后看不到最新消息
**原因：** 以前解密后的数据库是快照，新消息需要手动重新解密。

**现在不用管了**：最新版 `summarize.py` 每次运行都会自动重新解密，拿到的永远是最新数据。

### Q: 微信重新登录后工具报错
**原因：** 重新登录会生成新密钥，旧密钥失效。

**解决：**
```bash
# 方法一：使用密钥刷新命令
diting keys refresh

# 方法二：手动删除后重跑安装
rm -f ~/.diting/wechat-db-decrypt-macos/wechat_keys.json
bash install.sh
```

> 💡 `diting keys refresh` 需要微信处于登录状态，且 SIP 需临时关闭。

### Q: Intel Mac 可以用吗？
目前不支持。解密工具基于 arm64 架构的内存扫描实现。

## 技术原理

| 组件 | 说明 |
|------|------|
| **微信数据库解密** | 基于 [wechat-db-decrypt-macos](https://github.com/Thearas/wechat-db-decrypt-macos) |
| **存储** | 微信 Mac 版使用 SQLCipher 加密的 SQLite 数据库 |
| **密钥提取** | 通过 lldb 从微信进程内存中扫描出数据库加密密钥 |
| **AI 总结** | 支持导出纯文本后接入任意 AI 工具，或直调 API |

### 总结方法论

导出消息后，按以下框架进行分析：

1. **时间线梳理** — 按时间顺序排列消息，识别关键节点
2. **人物识别** — 标注主要发言者，识别互动关系
3. **主题提取** — 将零散消息归类为 2-4 个话题线
4. **上下文关联** — 结合历史消息，理解话题演变
5. **价值提炼** — 输出 actionable 的信息（商机、决策、待办等）
